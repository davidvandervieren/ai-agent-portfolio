As required by C.R.S. Section 24-33.5-1237, the Board of County Commissioners hereby
adopts the 2025 Colorado Wildfire Resiliency Code (the "Resiliency Code") and subsequent
versions thereto as may be adopted or amended by the Colorado Wildfire Resiliency
Code Board ("Resiliency Code Board"), with the following modifications:
A.
Delete all of Appendix C.
B.
The Effective Date of the Resiliency Code for the purpose of enforcement shall be
July 1, 2026.
C.
The Resiliency Code shall apply to parcels located in Weld County outside the corporate
limits of a city or town and outside the boundaries of a fire protection district,
and which are shown on the State Map for the Application of the 2025 Colorado Wildfire
Resiliency Code (or versions thereof subsequently adopted or amended by the Resiliency
Code Board) and designated:
1.
High Intensity Non-Federal; or
2.
Moderate Intensity Non-Federal; or
3.
Low Intensity Non-Federal.
4.
Exempting therefrom any thirty-five (35) acre or larger parcel with only one (1) residential
structure on it that does not abut a residential or commercial area.
(Weld County Code Ordinance 2026-06 )
Enforcement of the Resiliency Code to applicable parcels in Weld County shall be by
the Colorado Division of Fire Prevention and Control pursuant to request of the Board
of County Commissioners in accordance with C.R.S. Section 24-33.5-1237(2)(d).
(Weld County Code Ordinance 2026-06 )

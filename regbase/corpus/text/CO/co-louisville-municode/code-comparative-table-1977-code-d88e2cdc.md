No table is necessary for the 1977 Code since the 1999 Code was not renumbered or
reorganized. Sections of the 1999 Code which also appeared in the 1977 Code are identified
by a reference to the 1977 Code in the history notes of such sections. The 1977 Code
was updated through February 20, 1996. For the location of ordinances adopted subsequent
thereto, see the next table.

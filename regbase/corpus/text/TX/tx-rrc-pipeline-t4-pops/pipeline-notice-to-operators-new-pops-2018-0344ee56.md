Austin, Texas September 2018 
RAILROAD COMMISSION OF TEXAS 
Oversight and Safety Division 
NOTICE TO PIPELINE OPERATORS 
New Version of Pipeline Online Permitting System Launches October 1 
The Railroad Commission of Texas (RRC) will launch a new version of the Pipeline Online Permitting 
System (POPS) on Monday, October 1, 2018. The new version will allow pipeline operators to 
continue to file applications for permits to operate a pipeline in Texas and pay annual pipeline mileage 
fees online. In addition, the mapping features have been enhanced in the new version. 
To help facilitate the rollout of the new version of POPS, the original POPS will be disabled the 
weekend of September 22, 2018. So, the last day to submit any permit applications online using the 
original version of the POPS is 5 p.m. Central Standard Time on Friday, September 21, 2018. Any 
permits submitted on or before September 21 will be reviewed before October 1, 2018. 
POPS is the web browser-based application that pipeline operators are required to utilize to 
electronically submit initial Application for Permit to Operate a Pipeline in Texas (Form T-4), Pipeline T-4 
Permit Amendments (including changes in mileage, characteristics changes, etc.), Pipeline System 
Additions, Pipeline T-4 Permit Inactivations and Pipeline T-4 Permit Renewals. POPS also provides 
for generation of Pipeline T-4 Permit Approval Letters when a Pipeline T-4 Permit is approved for an 
operator in the system. The application also allows the public and other state agency personnel to 
access documents that have been submitted electronically, as well as reports based on Pipeline T-4 
Permit data. 
If there are any questions, please contact the RRC’s Pipeline Permitting department at 512-463-7058 
or pipelinepermits@rrc.texas.gov.

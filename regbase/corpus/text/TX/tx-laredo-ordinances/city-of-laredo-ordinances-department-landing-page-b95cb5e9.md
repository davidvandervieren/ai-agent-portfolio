The Building Development Services is responsible for various ordinances and amendments to the Code of Ordinances. Periodically we update existing or create new ordinances to better establish guidelines and regulations for various aspects of construction, development, and code enforcement.
Code of Ordinances The complete City of Laredo Code of Ordinances can be found online using the Municode website.
Land Development Code The Land Development Code Book states regulations for development of properties, in regards to zoning requirements, parking requirements, and other aspects of land development.
Subdivision Ordinance The Subdivision Ordinance Handbook lays out the process and requirements by which a plat is created and recorded with the Planning and Zoning department. The Building Development Services also reviews plats as part of the development process.
